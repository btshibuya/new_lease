# new_lease

新リース会計基準（企業会計基準第34号、2027年4月1日以後開始する連結会計年度から適用）の連結決算対応として、**グループ内リースの個社修正仕訳・連結修正仕訳を作成するアプリ**です。

- 前提：借手は個別でオンバランス済み（使用権資産・リース負債）、貸手はオペレーティング・リース
- 要件定義書：[docs/requirements.md](docs/requirements.md)
- アプリ：[app/](app/)（外部ライブラリ・外部通信なしの静的Webアプリ）

## 起動方法

Node.js 18 以上が必要です（追加のパッケージのインストールは不要）。

```bash
npm start          # http://127.0.0.1:8080/ で起動
npm test           # 自動テスト（設例の期待値、全方針の組合せの検算、ミューテーションテストなど）
```

ES モジュールを使うため、`index.html` をファイルとして直接開くのではなく、上記のローカルサーバー（または任意の静的ファイルサーバー）経由で開いてください。

## 主な画面

画面の左側のメニューに、作業の手順（1〜6）を番号つきで並べています。各手順の右端の記号は状態を表します（✓：入力済み、赤い数字：確認事項の件数、・：未入力・未確定）。選んでいる手順の下には、会計方針の14論点と確認事項のある検算が子項目として表示され、押すとその箇所へ移動します。

| メニュー | 内容 |
|---|---|
| 全体の状況 | 主な数値、グループ内リースの関係図（出資関係図の配置）、年度別の連結損益影響、消去差額の推移、検算サマリー |
| 1 会社を登録する | 決算月・法定実効税率・非支配株主持分比率など、税率・持分比率の履歴 |
| 2 会計方針を選ぶ | 論点ごとのラジオボタン、既定値（推奨）と根拠、選択肢ごとの設例（仕訳例・グラフ）、協議メモ |
| 3 契約を登録する | 契約一覧（絞り込み）、CSVでの一括取込（テンプレートをアプリから取得）、契約編集、返済スケジュール、消去差額のグラフ、年度別サマリー、個別帳簿との突合、契約タイムライン |
| 4 仕訳を確かめる | 個社修正・連結修正仕訳、根拠（計算式・月次の元仕訳）、T勘定、手入力仕訳、CSV出力 |
| 5 連結精算表・CF・注記 | 個別→個社修正→連結修正→連結、損益ブリッジ、連結CF消去額、注記（新リース会計基準）の調整額、満期分析 |
| 6 検算・期間の確定 | 仕訳とは別の計算経路で期待値を作る独立検算など18項目（CHK-00〜17）、期間確定（スナップショット） |
| データの保存・変更履歴 | JSON入出力、科目名カスタマイズ、監査ログ（ハッシュ連鎖による簡易的な改ざん検知） |
| 使い方・設例 | アプリの使い方、要件定義書の設例との対応 |

画面で計算された数値（下線つき）を押すと、右側に「計算の確認」欄が開き、計算式・契約ごとの内訳・元になった仕訳と出典を表示します（Esc キー・×ボタン・メニューの切替えで閉じます）。会社マスタと契約の編集画面は、画面下の「保存して再計算」で保存します。保存していない変更があるまま別の画面へ移ろうとすると確認が表示されます。

## 画面デザイン

ビジネストラストのデザイン（[design/DESIGN.md](design/DESIGN.md)、見本は [design/design-sample.html](design/design-sample.html)）に従っています。

- `app/bt-style.css`：`design/style.css` の写し（色・文字・ヘッダー・左メニュー・表・計算の確認欄などの土台）。値を変えるときは `design/` 側を直してから写します。
- `app/styles.css`：土台にない部品（グラフ・仕訳カード・会計方針カードなど）と、配色の切替え（右上の「配色」：ビジネストラスト〈既定〉／ブルー／ライトブルー／グリーン／レッド／ティール／ダーク）。

## 構成（共通部品とカスタマイズ）

```
app/src/engine/   共通部品（計算・仕訳生成・検算。UIに依存しない純粋な関数）
  schedule.js     月次スケジュール（実効金利法・定額償却・貸手の定額収益）
  elimination.js  個社修正・連結修正仕訳（個別仕訳の取消として作成し根拠を保持）
  checks.js       自動検算
  policies.js     会計方針の定義（選択肢・既定値・根拠）
  accounts.js     勘定科目定義（表示名はユーザー設定で上書き）
  data.js         取込データの検証・無害化、CSV出力、監査ログ
app/src/ui/       画面（カスタマイズ層：画面・帳票レイアウト）
tests/            自動テスト
```
