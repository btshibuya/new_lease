# デザイン仕様（ビジネストラストの業務アプリ）

連結税効果注記ツールで利用者と決めたデザインです。ほかの業務アプリ（注記アプリに限らない）も、これに合わせます。
**見本ページ**：`note-common/notekit/static/design-sample.html`（ブラウザで開くと全部品を確認できる）
**正（ソース）**：`note-common/notekit/static/style.css` と `bt-logo.png`。値を変えるときはこの2つを直す。

## 2. 画面の骨組み
```
┌────────────────────────────────────────────────────────────┐
│ [ロゴ] │ アプリ名                                  入力者 [    ] │ ← 白地。下に紺→青→水色の線（3px）
├──────────┬───────────────────────────────┬──────────────────┤
│ 単体｜連結 │ パンくず                              当期｜前期 │ 計算の確認       │
│ 会社 [▼]   │ 会社名 [バッジ]                                │ （数値を押すと開く）│
│ ① 手順 ✓  │ ② 手順の見出し                                 │                  │
│ ② 手順 2  │ 本文（表・入力欄・お知らせ）                    │                  │
│   ・子項目 │                                                │                  │
│ ③ 手順 ・ │                                                │                  │
│ 設定・履歴 │ [保存して再計算][変更を破棄][次へ →] 保存済み    │                  │
└──────────┴───────────────────────────────┴──────────────────┘
```
- **左のツリー**（幅250px）：上のメニュー・タブは使わない
  - 最上部に**モードの切替え**（例：単体（会社別）｜連結）。**モードごとに別のツリー**を出す（縦に並べない）
  - 番号つきの手順。選択中は水色の地＋左に水色の線、番号の丸は青→水色のグラデーション、ほかは灰色
  - 手順ごとの状態：✓（緑）入力済み／数字（赤い丸）確認事項の件数／・（灰）未入力
  - 子の項目（明細の行・注記の節など）は手順の下に、左の線と点で並べる。押すと該当の行・見出しへ移動して黄色く光らせる
  - 最下部に共通（設定・変更履歴）
- **本文**：手順の見出しは「番号の丸＋手順名」。下に固定の保存バー
- **右の「計算の確認」欄**（幅560px）：数値を押すと開き、**メニューを切り替えたら閉じる**（Esc でも閉じる）

## 3. 部品
| 部品 | クラス | 決まり |
|---|---|---|
| ボタン | `btn` `btn-primary` `btn-danger` `btn-sm` | 主の操作は濃い紺、削除は赤枠 |
| 切替え | `seg`（中に button、選択中は `on`） | 当期／前期、注記の形／会社別に展開 など |
| バッジ | `badge` `badge ok` `badge warn` `badge cls` | 区分・状態 |
| 出典 | `src` `src journal` `src manual` `src carry` | 「PDF p.2」（押すとPDFの該当箇所）／「仕訳 12行」／「手入力」／「繰越」 |
| お知らせ | `alert alert-info / -warn / -ok / -err` | 説明は青、確認事項は黄、問題なしは緑、エラーは赤 |
| 表 | `tbl`（見出しは淡い青）、`total`（合計行）、`sec`（区分の行）、`excluded`（灰色）、`indent` | 金額は `num`（右寄せ） |
| 押せる数値 | `vcell`（セル）／`v`（文中） | 押すと計算の確認欄。参照箇所は `hl`、開いている値は `hl-main` |
| 入力 | `form-grid` | ラベル 220px＋入力欄。入力欄の横に出典のバッジ |
| 数値の見出し | `kpi` の中に `k` | 件数・合計など |

## 4. 数値と文言の決まり
- 金額：右寄せ・桁区切り・**マイナスは「△」**（例 △1,234）。率も「△1.91%」
- 注記の単位（千円・百万円）は切捨て（設定で四捨五入）。浮動小数点の誤差で1ずれないよう円未満6桁で丸めてから切り捨てる
- 文言は**やさしい日本語**：利用者は会計の専門家だがプログラミングには詳しくない。英語・専門用語は使わない（使うなら一言で説明）
- ボタンの文言は動作を表す（「保存して再計算」「この内容を入力に反映する」「次へ：○○ →」）
- 確認事項は「何が・いくら・どう違うか」を書く（例：「リース債務：明細の合計 20,000,000円 と試算表の残高 21,000,000円 が △1,000,000円 違います」）

## 5. 検証できる画面の決まり（デザインの一部として必ず入れる）
- 計算した数値はすべて押せる（`vcell`）。押すと：値・式（部品を押すと移動）・値を入れた式・**会社別の内訳**・率なら率の計算過程・ドリルダウン表（▶で開く、会社コードつき）・出典（PDFの該当箇所をハイライト）
- 入力値の横には出典のバッジ
- 保存していない変更があるときは、画面移動・閉じる前に確認

## 6. ほかの技術で作るアプリに当てはめるとき
- **素の HTML/JS（注記アプリなど）**：`/kit/style.css`・`/kit/util.js`・`/kit/panel.js`・`/kit/sidebar.js` をそのまま使う（`note-common/README.md`）
- **React など**：`style.css` をコピーしてグローバルに読み込み、上のクラス名で部品を作る。`:root` の変数だけ使ってもよい。
  左のツリー・計算の確認欄は `sidebar.js`・`panel.js` の構造（クラス名・動き）をまねる
- 既存アプリにテーマ切替え（配色の選択）がある場合は、「ビジネストラスト」を既定の配色として追加する
